# قانون نمایش راست‌چین با نویسهٔ کنترلی (هارنس‌های بدون HTML — ZCode و امثالش)

این قطعه را عیناً به فایل دستورهای عامل خود اضافه کنید: `AGENTS.md`، `CLAUDE.md` یا هر فایلی که هارنس پیش از هر پاسخ می‌خواند.

این قانون برای رندرکننده‌هایی است که تگ HTML را نویزهٔ متن می‌شمارند و حذف می‌کنند؛ نخستین هارنس آزمون‌شده ZCode است (رندرر Streamdown، آزمون ۲۰۲۶-۱۱-۲۰). اگر رندرکنندهٔ شما HTML خام را عبور می‌دهد — مثل AutoClaw — از [قانون بستهٔ div](autoclaw-rtl-law.md) استفاده کنید. دستور تشخیص اینکه کدام قانون برای هارنس شما درست است: [docs/harnesses.md](../docs/harnesses.md).

---

## قانون نمایش راست‌چین

**زمینه:** رندرکنندهٔ پیام پایهٔ جهت پاراگراف را راست‌به‌چپ نمی‌گذارد و تگ HTML هم حذف می‌شود؛ پس نه بستهٔ `div` در دسترس است و نه `direction` از محتوا تشخیص داده می‌شود. نتیجه، جابه‌جایی واژه‌های لاتین، اعداد و پرانتزها در هر شکست خط است. راه‌حل، نویسه‌های کنترلی دوجهتهٔ یونیکد است که داخل خود متن زندگی می‌کنند و از هر پاکسازی عبور می‌کنند: جفت **RLI (U+2067)** و **PDI (U+2069)**. این دو نویسه نامرئی‌اند.

**۱. ایزولهٔ الزامی.** هر بلوکی که نویسهٔ فارسی دارد — پاراگراف، تیتر، آیتم فهرست، خانهٔ جدول، نقل‌قول — بین RLI و PDI بسته می‌شود. هیچ پیامی — حتی یک خط — بدون این جفت فرستاده نمی‌شود.

**۲. آرایش دقیق.** جفت ایزوله **داخل** نحوش مارک‌داون می‌نشیند؛ نشانه‌های مارک‌داون بیرون جفت می‌مانند تا پارس نشکنند:

```
## ⁧تیتر فارسی⁩
- ⁧آیتم فهرست با واژهٔ latin⁩
**⁧متن بولد⁩**
> ⁧نقل‌قول⁩
| ⁧عنوان ستون⁩ | ⁧ستون دیگر⁩ |
```

**۳. استثنای کد.** بلوک کد، کد درون‌خطی و سطرهای فقط‌لاتین (فرمان، مسیر، آدرس، جدول اعداد) هرگز بسته نمی‌شوند؛ کد باید چپ‌به‌راست بماند.

**۴. ممنوعیت جانشین‌های ناکارآمد.** متن خام بدون جفت به‌هم می‌ریزد. RLM تنها در آزمون واقعی شکست خورد (اگرچه در آغاز پاراگراف اثر می‌گذارد، در شکست خط از میدان خارج می‌شود). بستهٔ `div` در این هارنس به‌صورت متن خام دیده می‌شود. RLE/PDF هم کار می‌کند اما RLI/PDI ترجیح دارد: ایزوله، سطح جهت را به متن بیرون از خودش نشت نمی‌دهد.

**۵. تفکیک فایل‌ها.** فایل‌های داده که ماشین می‌خواند (JSON، CSV، پیکربندی، ورودی پارسر) هرگز نویسهٔ کنترلی نمی‌گیرند؛ فقط خروجی گفت‌وگویی که انسان می‌خواند.

**۶. پیام‌های کوتاه.** پاسخ یک‌خطی فارسی هم جفت می‌خواهد؛ استثنا وجود ندارد.

**۷. بازرسی.** پیش از ارسال متن بلند، `python tools/rtl_isolate.py <file> --check` را اجرا کن و سطرهای بدون ایزوله را رفع کن.


## قالب نادرست

```
فایل main.py در خط 42 تابع parse_response را صدا می‌زند و اگر HTTP 429 برگردد (تلاش مجدد بعد از 3 ثانیه) پیام "rate limited" چاپ می‌شود.
```

بدون جفت، جزیره‌های لاتین و پرانتزها به‌هم می‌ریزند.

```
<div dir="rtl">

متن پاسخ

</div>
```

در این هارنس تگ‌ها رندر نمی‌شوند؛ به‌صورت متن خام دیده می‌شوند.
